Project Overview

This project is an advanced AI-powered knowledge assistant built using Retrieval-Augmented Generation (RAG). It enables users to upload domain-specific documents and interact with them through natural language queries — with full transparency into how answers are generated.

Key Highlights

Context-Aware Answers

LLM-powered answer generation grounded in uploaded document context using RAG architecture.

Semantic Search

Vector embeddings with FAISS enable semantic document search beyond keyword matching.

Auto Summarization

Automatic document summary generation on upload, stored in SQLite for instant retrieval.

Explainable AI (XAI)

Transparent retrieval with similarity scores, source attribution, and chunk-level traceability.

Comparison Mode

Side-by-side comparison of RAG-augmented vs direct LLM responses to demonstrate RAG value.

Evaluation Metrics

Performance benchmarking with MRR, NDCG, and t-SNE embeddings visualization.

SQLite Integration

Structured storage of documents, summaries, and query logs for analytics and auditing.

Response Caching

In-memory caching of embeddings and responses to reduce API costs and latency.

Security & Authorization

  • Secure Identity: Multi-field registration (Full Name, Mobile, Email) with Email OTP validation for all new users.
  • Explainable AI: Built-in Confidence meter highlighting RAG validity and source provenance.
  • PII Detector: Active regex-based scanning over all AI outputs to protect sensitive data.
  • Admin Control: Hierarchy-based session management (`admin`/`user`) with credit-scoped permissions.

Future Expansion Plan

To preserve backend stability while ensuring scalability, the following features are actively mapped for Phase 2:

  • Full Multi-Agent Orchestration: Upgrading prompt schemas into a fully collaborative Swarm format.
  • Knowledge Graph Integration: Transmuting FAISS data into Neo4j for reasoning.
  • Offline/Low-Resource Mode: Deploying open-source fallbacks for absolute data privacy.
