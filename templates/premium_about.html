Project Overview

This project is an advanced AI-powered knowledge assistant built using Retrieval-Augmented Generation (RAG). It enables users to upload domain-specific documents and interact with them through natural language queries — with full transparency into how answers are generated.

Key Highlights

Context-Aware Answers

LLM-powered generation grounded in uploaded document context using RAG architecture.

Explainable AI (XAI)

Transparent retrieval with similarity scores, source attribution, and chunk-level traceability.

Agentic Actions

Specialized agent prompts for automated Risk Auditing and Professional Profile extraction direct to email.

Comparison Mode

Side-by-side comparison of RAG-augmented vs Direct LLM responses to demonstrate exact RAG value.
